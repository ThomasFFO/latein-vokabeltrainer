Latein-Vokabeltrainer – PWA-Version

Enthalten:
- index.html
- manifest.webmanifest
- service-worker.js

Funktionen:
- lokale Speicherung der Vokabeln und des Lernstands
- adaptive Wiederholung
- Export und Import als JSON-Datei
- für iPhone und Mac optimierte Oberfläche
- offline nutzbar, sobald die PWA einmal über einen Webserver geladen wurde

Wichtig:
Eine PWA funktioniert nicht zuverlässig, wenn man index.html nur als lokale Datei öffnet.
Sie sollte über https:// oder einen lokalen Webserver bereitgestellt werden.

iPhone:
1. Seite in Safari öffnen.
2. Teilen antippen.
3. "Zum Home-Bildschirm" wählen.
4. Danach startet sie nahezu wie eine normale App.

Mac:
Die Seite kann in Safari geöffnet und – je nach macOS-Version – ebenfalls als Web-App hinzugefügt werden.

Datensicherung:
Über "Daten exportieren" eine JSON-Datei speichern.
Über "Daten importieren" kann diese Datei auf einem anderen Gerät eingelesen werden.
