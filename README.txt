Vokabelkasten 2.1 – korrigierte Version

Wichtig:
- Diese Version behebt die nicht reagierenden Eingabefelder/Buttons.
- Neue Kästen werden jetzt über ein sichtbares Namensfeld angelegt:
  Name eingeben -> „Kasten speichern“.
- Kästen können danach über das Auswahlfeld oben gewechselt werden.
- Vorhandene Daten aus älteren Versionen werden nach Möglichkeit automatisch übernommen.
- Der Service-Worker-Cache wurde auf eine neue Versionsnummer gesetzt, damit iPhone/Safari die korrigierte App lädt.
